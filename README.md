- **📱 Fully Responsive Design:** Optimized for a seamless viewing experience across desktops, tablets, and mobile devices.
- **🎨 Modern UI/UX:** Features a sleek layout with smooth-scrolling animations and micro-interactions.
- **🌓 Dynamic Interactive Elements:** Includes functional components like a mobile hamburger navigation toggle.

## 🛠️ Built With

This project is built purely using  web technologies, demonstrating strong foundational frontend capabilities:

- **HTML5:** For structured, semantic, and accessible web layouts.

- **JavaScript (ES6+):** For interactive components, scroll behaviors, and responsive logic.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps:

### Prerequisites
You only need a web browser and a code editor (like [Visual Studio Code](https://visualstudio.com)).

### Installation & Setup
1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate to the project folder:**
   ```bash
   cd your-repository-name
   ```
3. **Open the project:**
   - Double-click `index.html` to view it in your browser.
   - Alternatively, open the directory in VS Code and run it using the **Live Server** extension for real-time changes.
